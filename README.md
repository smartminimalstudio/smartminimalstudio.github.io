# Smart & Minimal Studio

Public studio and product marketing website. GitHub Pages serves `main:/docs`.

- Studio: `/`
- DETENT: `/products/detent/`
- Legacy personal Pages URLs receive compatibility redirects.

Smart & Minimal Studio is the umbrella brand. DETENT• retains its product identity, joined E/T wordmark, orange dot, current D33 presentation, animations and finish configurator.

This repository contains public marketing assets only. Do not add CAD, STL, STEP, 3MF, meshes, customer archives, offline assembly viewers or assembly PDFs. Paid DETENT files are delivered through Payhip at US$19 once for personal use. Commercial printing requires the existing separate written grant. The current edition remains in development; physical qualification is pending and no load rating is claimed.

Optional GA4 measurement is loaded through GTM only after visitor opt-in. Advertising is disabled. This site does not process payments. Language, palette and analytics choices remain in the visitor's browser. Hosting and payment processors have their own privacy practices.

Preview: `python3 -m http.server 8894 --directory docs`.

## Hosting

The commercial website is served by Cloudflare Pages Free at https://smartminimalstudio.pages.dev/. The GitHub Pages compatibility branch redirects older links; main/docs remains the marketing source. No printable geometry or paid manuals belong in the public site.

Build the static upload ZIP with `python3 scripts/package-site.py`. Upload that ZIP as a production deployment to the existing `smartminimalstudio` Pages project; do not create a new project for updates.

Commercial licence: [US$79 / 12 months](https://smartminimalstudio.pages.dev/products/detent/commercial), one-time payment with manual renewal. D33 project files remain a separate US$19 purchase. Checkout collects the named licensee and required licence acceptance; no paid geometry is hosted here.
